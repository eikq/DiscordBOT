# Jarvis memory safety

- Treat canonical SQLite records and their provenance as structured evidence.
- Preserve canonical IDs, confidence, status, timestamps, and source references.
- Never invent a memory edge or claim that retrieval succeeded when it did not.
- Resolve contradictions through explicit supersession; do not silently erase history.
- Keep SocialMemoryBrain intact as an existing source/projection.
- Qdrant or embeddings may help retrieval later but are not canonical truth.
- Persona may change wording, never verified facts, provenance, or uncertainty.
- Do not reveal restricted/private memory outside its policy scope.
