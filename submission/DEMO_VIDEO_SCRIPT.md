# สคริปต์วิดีโอเดโม Digital Me (ประมาณ 2–3 นาที)

## 0:00–0:15 — เปิดเรื่อง

“สวัสดีครับ โปรเจกต์นี้ชื่อ Digital Me เป็น Discord voice AI ที่ออกแบบมาสำหรับบทสนทนาภาษาไทยและไทยปนอังกฤษ จุดต่างคือบอทไม่ได้แค่ฟังคำสั่ง แต่พยายามเข้าใจบริบท ความสัมพันธ์ และรูปแบบการพูดของกลุ่มเพื่อนด้วย”

## 0:15–0:40 — ปัญหา

“Discord bot ทั่วไปมักตอบเป็นข้อความสั้น ๆ ไม่รู้ว่าใครเรียกใครว่าอะไร และเสียงสังเคราะห์ก็มักเป็นหุ่นยนต์ Digital Me จึงรวม speech-to-text, social memory, การสร้างคำตอบ และ voice conversion เป็นระบบเดียว”

## 0:40–1:10 — Public demo

1. เปิด `https://digital-me-thai-voice.piriyapong2551.chatgpt.site`
2. พิมพ์: `แกม กินข้าวยัง เย็นนี้เล่นเกมกันไหม`
3. กด **Run conversation**
4. ชี้ให้เห็น transcript, intent, memory และคำตอบที่เกี่ยวข้องกับคำถาม
5. สลับ **Demo Voice** / **Singing Style** และกดฟัง browser voice

พูดประกอบ: “หน้าเว็บนี้เป็น privacy-safe demo จึงไม่ปล่อยเสียงจริง น้ำหนักโมเดล หรือข้อมูลส่วนตัวของเพื่อนขึ้นสาธารณะ แต่แสดง logic หลักให้กรรมการทดลองได้ทันที”

## 1:10–2:05 — เดโมระบบจริงใน Discord

> ทำส่วนนี้เฉพาะเมื่อเจ้าของเสียงยินยอม และให้เห็นข้อความแจ้งว่ากำลังฟัง/บันทึก

1. เปิด dashboard ที่ `http://127.0.0.1:3000` และ Discord คู่กัน
2. เลือก server, notification channel, voice channel และ target ที่ยินยอม
3. เริ่ม listening/training แล้วให้ target พูดประโยคไทยปนอังกฤษ 1–2 ประโยค
4. แสดง transcript และสถานะ accepted/rejected พร้อมเหตุผลคุณภาพเสียง
5. หยุด capture หรือแสดงโมเดลที่เตรียมไว้แล้ว
6. เลือกโมเดล `best` แล้วสั่งให้พูดหนึ่งประโยคใน VC
7. ถามบอท: `เย็นนี้พวกเราจะเล่นอะไรกันดี` และให้เห็นคำตอบที่ใช้ memory แทนคำตอบสุ่มสั้น ๆ

พูดประกอบ: “เสียงสำหรับ train แยกเก็บเฉพาะ target ส่วนเสียงของคนอื่นใช้ได้เฉพาะการเข้าใจบริบท และระบบจะไม่เอาเสียงคนอื่นไปรวมใน dataset ของ target”

## 2:05–2:30 — สรุป

“Digital Me ทำให้ AI ใน Discord ฟังภาษาไทย รู้จักบริบทของกลุ่ม และตอบด้วยเสียงที่เป็นธรรมชาติมากขึ้น โดยยังแยกข้อมูลส่วนตัวออกจาก public demo โค้ดและเว็บทดลองเปิดให้ตรวจได้จากลิงก์ในสไลด์ ขอบคุณครับ”

## หมายเหตุการถ่าย

- อัดที่ 1080p และซูม UI 110–125% ให้อ่านง่าย
- ปิด/เบลอ Discord token, user ID, IP, path ส่วนตัว และบทสนทนาที่ไม่เกี่ยวข้อง
- ใช้หูฟัง ปิดเสียงรบกวน และอย่าเปิดเพลงที่มีลิขสิทธิ์
- ถ้าระบบจริงหน่วง ให้ใช้โมเดลที่ train ไว้ล่วงหน้าแทนการ train ในวิดีโอ
