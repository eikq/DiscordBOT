# Jarvis lab visual QA

Do not rewrite frontend architecture, Jarvis Core, or the knowledge-graph system.

## Hierarchy

1. Central 3D Core dominates (~30–40% of the stage).
2. Engineered orbit rings are holographic machinery, not CAD circles.
3. Graph labels are sparse; reveal on hover/selection/search.
4. Panels are secondary glass HUD, not debug cards.
5. Text stays sharp; bloom only on nucleus, pulses, selected nodes, energetic particles.

## Palette

Dark navy/black field. Cyan/ice for data and core light. Magenta/pink only as sparse HUD accents. No Stark/SAO branding copy.

## Verify at 1920x1080

- Core volume, camera, negative space
- Graph noise and orbit design
- Lighting, motion, typography, FPS
- High >60 FPS, Balanced smooth, Minimal low-GPU, 2D fallback
- Reduced-motion and hidden-tab pause
- Real IDLE/THINKING/MEMORY/TOOL/LISTENING/SPEAKING/NIGHT moods

Never claim live visual sign-off from unit tests or a headless black canvas.
